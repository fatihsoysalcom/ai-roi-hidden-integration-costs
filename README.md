# AI ROI Hidden Integration Costs

This example demonstrates how hidden integration costs can significantly impact the Return on Investment (ROI) of an Artificial Intelligence (AI) project. It simulates an AI investment scenario, first calculating ROI based on initial investment and expected benefits, then recalculating it by including often-overlooked integration expenses, revealing a potentially negative return.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
